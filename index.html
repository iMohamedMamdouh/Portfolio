Barcode Flow — Print barcode labels with speed and precision.

A responsive mobile and tablet application that connects directly to Odoo so every printed label matches the live record. Built for a furniture factory's packing line, it eliminates name mismatches and keeps inventory tracking clean.

Wasilaah Packaging — a barcode printing app tied directly into the packing workflow. It handles printing and formatting so inventory tracking stays clean, and was designed in Arabic to prevent product-name mismatches with the system. Because the app is connected to Odoo in real time, every product and label on the floor matches the official record.

  • Secure login with per-user permissions
  • Real-time printing via TSPL thermal printers
  • Responsive UI that works on phones and tablets
  • Clean Architecture — maintainable, scalable code
